# TrailCurrent Tiercel

Firmware for **Tiercel**, the TrailCurrent touch-and-knob controller: a 1.8"
round touch display inside a turning bezel, small enough to sit on a table
or mount by the door. It shows live state from the rig (climate, devices,
energy, water, air quality, levelling), talks to **Peregrine**, the rig's
voice assistant, and runs the room's **Playbill** media box, all through the
TrailCurrent Headwaters gateway.

Tiercel is the successor to [Capstan](https://github.com/trailcurrentoss/TrailCurrentCapstan),
and it shares Capstan's data model, MQTT contract and screen family. What
changes is the input. Capstan is a ring you turn and press. Tiercel is
**touch-first**: the knob only turns, and everything you select is a tap.

| | |
|---|---|
| Board | [Waveshare ESP32-S3-Knob-Touch-LCD-1.8](https://www.waveshare.com/wiki/ESP32-S3-Knob-Touch-LCD-1.8) |
| Display | 360×360 round IPS, ST77916 over QSPI, CST816 capacitive touch |
| Input | Detent knob (no push), touch, DRV2605 haptic motor |
| Audio | PDM microphone, PCM5100A DAC to a 3.5 mm jack |
| MCU | ESP32-S3R8 (8 MB octal PSRAM, 16 MB flash), plus an ESP32 co-processor |
| Stack | ESP-IDF 5.5 · LVGL 9.2.2 · EEZ Studio for the GUI |

## What it does

- **Climate:** set the temperature with the knob, tap the mode pill for Heat / Cool / Auto / Off.
- **Devices:** the lights and relays Headwaters assigns to this unit. Turn to choose, tap to switch.
- **Peregrine:** tap the orb and speak. It listens, thinks and answers through the headphone jack.
- **Playbill:** play, pause and skip media; switch to FM radio and tune with the knob.
- **Energy, Water, Air Quality, Leveling:** read-only live status.
- **Alerts:** door and safety alarms take over the screen with a buzz until tapped.
- **Clock:** four idle clock faces.
- **Settings:** theme, brightness, back gesture, haptics, knob ratio, units, clock face, snooze and timeout.

Every knob detent clicks the haptic motor, and taps, commits and back each have
their own heavier feel. When a knob-adjusted value reaches its limit (volume,
temperature, brightness, the end of a list), the next detent pulses instead of
moving. You feel the end stop without looking. See [docs/screens.md](docs/screens.md).

## Quick start

```sh
. <path-to-esp-idf-5.5>/export.sh

idf.py set-target esp32s3
idf.py build
idf.py -p /dev/ttyACM0 flash monitor
```

The USB-C port reaches **one chip per plug orientation**. If the port shows up
as a CH340 (`/dev/ttyUSB*`), you are talking to the ESP32 co-processor; flip
the plug to reach the ESP32-S3. See [docs/build.md](docs/build.md).

Before the first export from EEZ Studio, the firmware builds a **bring-up
screen** that exercises the display, touch, knob, haptics and audio. Open
`GUI/Tiercel.eez-project` in EEZ Studio and press **Ctrl+B** to export the real
UI into `main/ui/`, then build again.

## Repository layout

```
GUI/                  EEZ Studio project (Tiercel.eez-project) and fonts
main/                 the application: navigation, screens' behaviour, actions
main/ui/              GENERATED by EEZ Studio -- delete and re-export freely
components/
  tiercel_board/      display, touch, knob, haptics, backlight
  tiercel_audio/      PDM microphone and PCM5100A output
  tiercel_peregrine/  the voice client
  tiercel_config/     settings in NVS
  tiercel_model/      live rig state (incl. Playbill) the UI reads
  tiercel_mqtt/       the Headwaters MQTT contract
  tiercel_wifi/       station and setup-AP Wi-Fi
  tiercel_portal/     the captive setup portal
docs/                 documentation (this list)
DOCS/                 design source and vendor material
```

`main/ui/` holds only EEZ Studio's output. Every hand-written file lives in
`main/` or `components/`, so emptying `main/ui/` and re-exporting never loses code.
